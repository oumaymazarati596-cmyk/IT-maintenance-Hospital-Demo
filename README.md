#  IT Maintenance & Support Web Application (Prototype)
**Institut Mongi Ben Hmida - Direction des Services Informatiques (DSI)**

A Streamlit-based web portal designed to streamline IT incident reporting, provide technician diagnostic assistance, and visualize maintenance analytics for hospital IT infrastructure.

---

##  Key Features

* **Staff Incident Reporting Portal**: Allows medical and administrative staff to submit structured IT incidents with severity levels.
* **Technician Console**: Provides a structured workspace for IT support staff to view open tickets, execute troubleshooting checklists, and close incidents.
* **Smart Diagnostic Rules Engine**: Auto-generates probable root causes and technical action plans based on equipment types and error descriptions.
* **Analytics & Preventive Metrics**: Visualizes equipment failure trends and department incident distribution using Plotly charts.
* **GLPI Data Migration Interface**: Supports CSV import for synchronizing existing GLPI ticketing data.

---

## 🛠️ Tech Stack

* **Front-End / UI**: [Streamlit](https://streamlit.io/)
* **Database**: SQLite
* **Data Processing & Analytics**: Pandas
* **Data Visualization**: Plotly Express
